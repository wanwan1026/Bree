# Privacy Policy / 隱私權政策

**Last Updated / 最後更新：2026-10-22**

This Privacy Policy applies to the Discord applications **Buding (布丁)** and **Bree (布蕾)** operated for our Discord community.

本隱私權政策適用於本 Discord 社群所使用的 **布丁（Buding）** 與 **布蕾（Bree）** Discord 應用程式。

These applications are primarily designed for use within our own Discord community. We only access and process Discord data when it is necessary to provide the features described below.

這些應用程式主要供我們自己的 Discord 社群使用。我們只會在提供下述功能所必要的範圍內，存取及處理 Discord 資料。

---

# 1. General Privacy Principles / 一般隱私原則

Buding and Bree do **not**:

- Sell Discord API data or user data.
- Use Discord data for advertising.
- Use Discord data for commercial user profiling.
- Sell or provide user data to data brokers or advertising networks.
- Use message content to train machine-learning or artificial-intelligence models.
- Intentionally collect passwords, payment information, financial information, or other authentication credentials.
- Maintain an external database containing complete histories of users' Discord messages.

布丁與布蕾**不會**：

- 出售 Discord API 資料或使用者資料。
- 將 Discord 資料用於廣告。
- 將 Discord 資料用於商業性使用者側寫。
- 將使用者資料出售或提供給資料仲介商或廣告平台。
- 將訊息內容用於訓練機器學習或人工智慧模型。
- 主動收集密碼、付款資訊、金融資訊或其他驗證憑證。
- 在 Discord 平台外建立保存完整使用者聊天紀錄的資料庫。

Discord data is processed only when necessary to provide the stated community features.

Discord 資料只會在提供下列社群功能所必要的範圍內處理。

# 2. Buding (布丁)

## 2.1 Purpose / 用途

Buding is a Discord community bot designed primarily for a gaming-focused community.

布丁是一個主要服務於遊戲交流型 Discord 社群的機器人。

Buding currently provides the following major features:

布丁目前主要提供以下功能：

### A. Game Group-Finding / 遊戲揪團

Members can use the `/揪團` command to create game or activity groups.

使用者可以透過 `/揪團` 指令建立遊戲或活動揪團。

The user may provide:

- The selected game or activity.
- Planned time.
- Number of players needed.
- Optional notes.
- A Discord voice channel.

使用者可以提供：

- 遊戲或活動類型。
- 預計時間。
- 所需人數。

- Discord 語音頻道。

Buding then creates a Discord group-finding post, mentions the corresponding game-interest role, provides a link to the selected voice channel, and may create a discussion thread.

布丁會建立揪團公告、標記對應遊戲身分組、提供指定語音頻道連結，並可建立專屬討論串。

Information entered through this feature is used only to create and display the requested group-finding activity within Discord.

使用者透過此功能輸入的資料，只會用於建立並顯示該次 Discord 揪團活動。

Discord 身分組可能作為抽獎券使用。布丁會確認使用者目前是否持有所需的抽獎券身分組。

When a qualifying reward is obtained, Buding may grant a special Discord role with a unique role color.

當使用者抽中特殊獎項時，布丁可能自動發放具有特殊顏色的 Discord 獎勵身分組。

For this feature, Buding may process:

- Current Discord roles.
- Roles granted or removed as part of the gacha system.

此功能可能處理：

# 3. Bree (布蕾)

## 3.1 Purpose / 用途

Bree is a Discord community management, moderation, and utility bot.

布蕾是一個用於 Discord 社群管理、自動審核及社群功能的機器人。

---

### A. Invitation-Link Moderation / 外部邀請連結審核

Bree may inspect messages for prohibited external invitation links, including unauthorized Discord server invitations and certain LINE group/community invitation links.

布蕾可能檢查一般訊息中是否包含禁止的外部邀請連結，包括未經允許的 Discord 伺服器邀請，以及特定 LINE 群組／社群邀請連結。

For this feature, Bree may process:

此功能可能處理：

- Message content.
- URLs contained in messages.
- Discord user/member identity.
- Channel information.
- Member roles or permissions.

- 訊息內容。
- 訊息內包含的網址。
- Discord 使用者／成員身分。
- 頻道資訊。
- 成員的身分組或權限。

When a prohibited invitation is detected, Bree may:

偵測到禁止的邀請連結時，布蕾可能：

- Remove the offending message.
- Send a moderation record to a designated Discord moderation channel.
- Warn the member.
- Apply moderation actions such as banning the member when required by the server's moderation rules.

- 刪除違規訊息。
- 將違規紀錄送至指定的 Discord 管理紀錄頻道。
- 警告成員。
- 依伺服器管理規則執行 Ban 等管理措施。

These records remain within Discord and are used only for community moderation and administrative accountability.

這些紀錄保存在 Discord 內，只用於社群管理及管理紀錄。

Bree provides automated nickname formatting for the community.

布蕾提供社群暱稱格式管理功能。

This may include:

可能包括：

- Applying the server's required prefix and suffix when a member first interacts in the server.
- Allowing a member to enter a desired nickname in a designated nickname-change channel.
- Reading the submitted nickname text and applying it as the member's Discord server nickname.
- Automatically formatting a new member's nickname when they join.

- 成員初次在伺服器互動時，自動補上伺服器規定的暱稱前後綴。
- 允許使用者在指定改名頻道輸入希望使用的新暱稱。
- 讀取使用者輸入的暱稱文字並套用至 Discord 伺服器暱稱。
- 新成員加入時自動整理暱稱格式。

For this purpose, Bree may process the member's:

因此，布蕾可能處理：

- Discord identity.
- Current display name or server nickname.
- Text voluntarily entered in the designated nickname-change channel.
- Member roles needed for the nickname feature.

- Discord 身分資訊。
- 目前顯示名稱或伺服器暱稱。
- 使用者在指定改名頻道主動輸入的文字。
- 改名功能所需要的成員身分組。

Nickname input is used only to perform the requested nickname change.

改名頻道中輸入的文字只會用於執行使用者要求的暱稱修改。

在指定頻道中，布蕾可能讀取訊息，以判斷簡單的回覆類型，例如問候、感謝或問題。

Bree then selects a response from predefined local response data.

布蕾會從事先準備好的本地固定回答資料中隨機選擇回覆。

此功能為規則判斷與隨機回答系統，**不是**人工智慧或機器學習系統。

User messages processed by the Answer Book are not used to train AI or machine-learning models.

答案書處理的使用者訊息不會用於訓練 AI 或機器學習模型。
